# The Way of Living Order

Working material for a philosophical book: original notes, developing arguments, research, and earlier drafts. The documents distinguish the author's positions from proposed formulations and unresolved questions.

Start with [the book-development guide](Order%20of%20life/Book%20development/Start%20here.md) or [the working synthesis](Order%20of%20life/Book%20development/Working%20synthesis.md). The `Order of life` folder can also be opened as an Obsidian vault, where its internal wiki links work directly.

- `Life is matter organized.txt`: an original statement of the framework.
- `Order of life/`: thesis drafts and current book-development notes.
- `Older paper/`: earlier compilations and versioned Markdown and Word documents.

To save later changes, run these commands from this repository:

```sh
git add --all
git commit -m "Update book notes"
git push origin main
```

A local commit records a version on this computer. A successful push copies committed changes to GitHub. Backups are manual; editing a note does not automatically commit or upload it.

Obsidian application settings, plugins, credential files, and temporary files are excluded by `.gitignore`. The writing and source documents remain the backup's focus.
